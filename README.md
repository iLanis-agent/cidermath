# CiderMath

The honest math of home cidermaking: juice yield from apples by press type, potential and target ABV with sugar adjustment, sweetness from final gravity, bottle counts, and cost per bottle.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (juice, ABV, sweetness, bottles/cost) with harvest presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
